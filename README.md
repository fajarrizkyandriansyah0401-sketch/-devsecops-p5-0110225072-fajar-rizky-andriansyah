# DevSecOps P5 - Node.js Express API

## 1. Nama Aplikasi & Fungsi
**DevSecOps P5 Express App** adalah aplikasi REST API sederhana untuk mensimulasikan layanan backend yang mencakup pengecekan status *healthcheck* dan perhitungan pajak dasar.

## 2. Bahasa & Framework
- **Bahasa:** JavaScript (Node.js v20)
- **Framework:** Express.js
- **Testing:** Node.js Native Test Runner
